처리 정보와 목적

구분범위 및 목적
기기의 기록제목·일기·필기·사진·꾸미기·즐겨찾기. 작성과 내보내기를 위해 기기에서 처리하고 암호화 저장합니다.
클라우드 기록백업을 켠 경우 암호문과 암호화 키 봉투. 기록 원문과 원본 키는 서버에 보관하지 않는 구조입니다.
계정·운영인증 제공자 ID, 이메일(해당 시), 암호문 크기·버전·백업 시각, 삭제 상태. 인증·백업 운영·삭제에 사용합니다.
결제·광고스토어 구매 검증 자료와 권한, 선택된 광고 SDK가 처리하는 기기·광고 관련 정보. 실제 광고 설정·동의 지역별 항목을 출시 전에 확정합니다.

청소년과 광고

출시 계획은 중학생을 포함한 만 13세 이상입니다. 나이 구간과 거주 지역을 이 기기에만 저장하고 생년월일은 수집하지 않습니다. 만 14세 미만은 광고·계정·결제 없이 로컬 작성과 내보내기를 이용합니다. 대한민국 외 거주자의 만 16세 미만 계정·결제는 지원하지 않습니다. 보호자 동의 확인 기능은 아직 제공하지 않습니다.

광고는 비개인화 요청과 G 등급 상한을 적용하며 청소년 요청에는 SDK의 연령 제한 처리를 사용합니다. 비개인화 광고도 IP 주소·기기 식별자·광고 상호작용·진단 정보를 처리할 수 있습니다. UMP가 요구하는 동의 및 개인정보 선택 화면을 제공합니다. 일기 본문·사진·필기·제목을 광고 SDK에 보내지 않습니다.

공통 로그인과 앱별 가입

네컷 로그와 로그인 계정·비밀번호·소셜 로그인 설정을 공통 사용합니다. 각 앱에 별도로 가입하며 데이터·구매·탈퇴는 앱별로 관리합니다. 이 앱에서 탈퇴해도 네컷 로그와 공통 로그인 정보는 유지됩니다. 공통 로그인 전체 삭제 경로와 보관 기한은 출시 전 확정해야 합니다.

암호화와 복구

관리자용 복호화 키는 제공하지 않습니다. 복구키와 기존 기기의 키를 모두 잃으면 기록을 복원할 수 없습니다. 암호화가 감염되거나 탈취된 단말까지 완전히 보호한다는 뜻은 아닙니다. PDF·PNG로 직접 내보낸 결과는 평문입니다.

외부 서비스와 이전

연결 예정인 Supabase 인증·DB·스토리지, Vercel 서버 함수, Google·카카오·Apple 인증, AdMob, Google Play·App Store 각각의 실제 처리 항목·수탁자·보관 국가·이전 근거·보관 기간을 운영 설정과 함께 명시해야 합니다. 현재 문서는 수집 없음이나 이전 없음으로 선언하지 않습니다.

보관과 파기

백업 버전 수·미완료 업로드 정리 기한·계정 삭제 처리 기한·삭제 식별자 보관 기간·법정 보관 예외는 미확정입니다. 서버 삭제 작업은 재시도하며, 접수와 완료를 구분합니다. 오프라인 기기와 사용자가 외부로 내보낸 파일은 즉시 원격 삭제할 수 없습니다.

권리 행사

계정 삭제 안내에서 경로를 확인할 수 있습니다. 본인 확인이 필요하며 일기 원문이나 복구키를 제출할 필요는 없습니다. 운영자의 열람 가능 범위는 운영 메타데이터로 제한됩니다.
