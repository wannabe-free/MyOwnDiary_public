삭제 범위

이 앱의 가입 상태를 종료하고 암호화 백업·키 봉투·객체를 삭제합니다. 네컷 로그의 가입·구매·데이터와 공통 로그인 계정·소셜 연결은 유지됩니다. 공통 로그인 자체의 삭제 경로와 보관 기한은 출시 전에 별도로 확정하여 안내합니다. 삭제 시작 후 서버는 재업로드를 거부합니다. 접수 상태와 실제 완료 상태를 구분합니다.

기기의 기록

먼저 편집 파일과 복구키를 안전한 곳으로 내보내세요. 기기에만 보관할 데이터는 계정과 분리해야 합니다. 이미 내보낸 외부 파일과 오프라인 기기의 즉시 삭제는 보장하지 않습니다.

처리 기간과 예외

삭제 완료 목표 기간, 백업 보존 기간 및 최소 삭제 식별자·법적 보관 정보의 보유 기간은 운영 정책 확정 전입니다. 정식 공개 전에 구체적으로 안내해야 합니다.
