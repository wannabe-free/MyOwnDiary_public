다이어리 이용약관 초안

서비스 범위

개인 다이어리 작성·꾸미기·로컬 저장·내보내기를 제공합니다. 로그인 없이 로컬 기능을 사용할 수 있으며 클라우드 백업에는 계정과 키 설정이 필요합니다. 백그라운드 실행은 운영체제의 제한을 받습니다.

기록과 복구키

사용자는 기록과 복구키를 안전하게 보관해야 합니다. 비밀번호 재설정은 기록 복호화 키를 복원하지 않습니다. 개발자에게도 기록을 복원하는 우회 키가 없습니다. 무제한·영구 백업이나 완벽한 보안을 약속하지 않습니다.

광고 제거 구매

광고 제거는 비소모성 1회 구매로 준비됩니다. 실제 가격·국가·플랫폼 간 권한 정책은 스토어 상품 설정 전에 확정합니다. 구매 복원과 검증된 환불·취소 상태를 반영하며 기본 저장·복원은 결제로 제한하지 않습니다. 환불 절차는 구매한 스토어의 적용 정책에 따릅니다.

계정 종료

이 앱의 탈퇴는 본인 확인 후 접수하며 해당 앱의 서버 백업과 키 봉투를 삭제합니다. 네컷 로그와 공통 로그인 계정·카카오 연결은 유지됩니다. 앱별 가입·탈퇴·구매·데이터는 별도이며 비밀번호·소셜 로그인 설정 변경은 공통 적용됩니다. 삭제 처리 기간과 필요한 법적 보관 예외는 정식 약관에서 명시합니다.

출시 전 확정 항목

운영자·대상 연령·서비스 지역·유료 조건·책임 범위·분쟁 처리·약관 변경 통지 절차·효력 발생일을 법률 검토와 함께 확정해야 합니다.
